تصمیم‌گیری روی متن، در میلی‌ثانیه

Laya یک «موتور تصمیم» است: یک متن یا JSON را می‌خواند و به چند سؤال مشخص جواب می‌دهد (کدام گزینه؟ چقدر؟ بله یا نه؟). همه‌ی جواب‌ها را در یک بار خواندن می‌دهد، همراه با احتمال هر گزینه. متن تولید نمی‌کند، پس نه خروجی نامعتبر می‌دهد و نه چیزی از خودش می‌سازد.

همین حالا امتحان کن ↓نصب روی سیستم خودت
import laya
agent = laya.load("convaiinnovations/laya")

r = agent.predict(
  "We were billed twice. Refund today or we cancel.",
  {"refund": {"type": "noul",
    "instructions": "Does the customer ask for money back?"}})

r["answers"]["refund"]["noul"]   # → 0.79 = P(yes)

Laya چیست و کی به کارش ببریم؟

⚡سریع

یک forward pass برای همه‌ی سؤال‌ها؛ حدود ۳۳ میلی‌ثانیه روی GPU (طبق سازنده). روی CPU معمولی چند صد میلی‌ثانیه.

🎯خروجی تایپ‌شده

جواب همیشه یکی از گزینه‌هایی است که خودت تعریف کرده‌ای. JSON خراب، متن اضافه و parse کردن ندارد.

📊احتمال کالیبره‌شده

برای هر گزینه یک احتمال می‌دهد. می‌توانی بگویی «اگر مطمئن نبود، به انسان بسپار».

LayaLLM (مثل GPT یا Llama)
خروجیانتخاب از گزینه‌های مشخص + احتمالمتن آزاد
سرعتیک بار خواندن، میلی‌ثانیهتولید کلمه‌به‌کلمه، معمولاً ثانیه
مناسب برایدسته‌بندی، مسیریابی، فیلتر، امتیازدهی، تصمیم بله/خیرنوشتن، خلاصه، گفتگو، استدلال چندمرحله‌ای
محدودیتمتن کوتاه (۵۱۲ توکن در مدل انگلیسی)؛ حساب و مقایسه‌ی عدد را خوب انجام نمی‌دهدکند و پرهزینه؛ ممکن است خروجی نامعتبر بدهد
choiceکدام گزینه؟

از بین چند برچسب یکی را انتخاب می‌کند. مثال: بخش مسئول تیکت (مالی / فنی / سایر).

scoreچقدر؟

روی یک مقیاس مرتب امتیاز می‌دهد. مثال: فوریت از ۰ (عادی) تا ۲ (بحرانی).

noulبله یا نه؟

احتمال «بله» را برمی‌گرداند. مثال: آیا مشتری تهدید به لغو کرده؟

استفاده

۱. بارگذاری و اولین پیش‌بینی

مدل را یک بار بارگذاری کن (چند ثانیه) و بعد هر چقدر خواستی بپرس:

import laya

agent = laya.load("convaiinnovations/laya")          # English checkpoint

state = "Hi, we were billed twice for March. Please refund the duplicate today or we will cancel our plan."
questions = {
    "department": {"type": "choice", "instructions": "Which department should handle this?",
                   "criteria": {"billing": "invoices, payments, refunds",
                                "technical": "bugs, outages, system errors",
                                "other": "everything else"}},
    "urgency":    {"type": "score", "instructions": "How urgent is this?",
                   "criteria": ["not urgent", "soon", "blocking"]},
    "churn_risk": {"type": "noul", "instructions": "Does the user threaten to cancel or leave?"},
}

result = agent.predict(state, questions)
answers = result["answers"]
print(answers["department"]["choice"])        # "billing"   (probability 0.99)
print(answers["department"]["probabilities"]) # probability of every label
print(answers["urgency"]["score"])            # 1.77 -> between "soon" (1) and "blocking" (2)
print(answers["churn_risk"]["noul"])          # 0.88 -> probability of "yes"

۲. شکل سؤال‌ها و جواب‌ها

نوعcriteriaفیلدهای جواب
choice{"label": "description", ...} یا ["a", "b"]choice برچسب برنده، probabilities احتمال هر برچسب
scoreفهرست سطح‌ها، از پایین به بالا: ["low", "mid", "high"]score امتیاز مورد انتظار (عدد اعشاری)، probabilities برای هر سطح ("0"، "1"، …)
noulاختیاری: {"true": "...", "false": "..."}noul احتمال «بله» (۰ تا ۱)

هر جواب answer_confidence هم دارد: اطمینان کالیبره‌شده که برای همه‌ی نوع‌ها قابل مقایسه است. با آن می‌توانی آستانه بگذاری، مثلاً اگر زیر ۰٫۶ بود به انسان بسپاری.

۳. فارسی و زبان‌های دیگر: Router

مدل پیش‌فرض انگلیسی است. Router زبان متن را تشخیص می‌دهد و متن غیرانگلیسی (از جمله فارسی) را به laya-multilingual (بیش از ۱۰۰ زبان) می‌فرستد:

from laya import Router

router = Router()                      # downloads a checkpoint on first use
r = router.predict("دو بار از حسابم پول کم شده، لطفاً برگردانید.", questions)
print(r["routing"]["model"])           # "multilingual"
print(r["answers"]["department"]["choice"])

# force a checkpoint, and read long documents (multilingual reads up to 8192 tokens)
r = router.predict(long_text, questions, model="multilingual", max_len=8192)

۴. تعداد زیاد: batch

اگر یک سؤال را روی تعداد زیادی متن می‌پرسی، با هم بفرست تا در یک بار اجرای مدل پردازش شوند (روی GPU چند برابر سریع‌تر است):

results = agent.predict_batch(["ticket one ...", "ticket two ...", "ticket three ..."], questions,
                              batch_size=32)
for r in results:
    print(r["answers"]["department"]["choice"])

۵. از روی schema (Pydantic)

from typing import Literal
from pydantic import BaseModel
import laya

class Ticket(BaseModel):
    department: Literal["billing", "support", "sales"]
    urgency: Literal[0, 1, 2]
    needs_human: bool

values = laya.decide(agent, state, schema=Ticket)   # {"department": "billing", "urgency": 2, "needs_human": True}

۶. از خط فرمان

laya "My payment failed twice" --preset triage
laya "My payment failed twice" --preset triage --json

سؤال‌های آماده (preset): triage (پشتیبانی مشتری)، email، guard (محافظ ورودی LLM)، moderation (ایمنی محتوا)، router (انتخاب مدل). در پایتون هم هستند: laya.triage_questions() و بقیه.

نکات عملی

این نکته‌ها را موقع ساختن کنترل چراغ راهنمایی با Laya روی مدل واقعی اندازه گرفتیم.

متن را کوتاه و متمرکز نگه دار

مدل انگلیسی فقط ۵۱۲ توکن را می‌خواند و بقیه بریده می‌شود. وقتی وضعیت ۹ چهارراه را در یک JSON بزرگ دادیم، برای همه‌شان یک جواب غلط یکسان داد. با یک متن کوتاه برای هر مورد درست شد.

عدد را به کلمه تبدیل کن

Laya ماشین‌حساب نیست. با «۱۴ ماشین در برابر ۱۱» دقتش حدود ۵۰ تا ۷۵ درصد بود. با «heavy در برابر light» بهتر شد، و وقتی مقایسه را صریح گفتیم («More cars are waiting on the north-south road») روی همه‌ی ۷۵ حالت آزمایش‌شده درست جواب داد.

قانون را در instructions بنویس

مثلاً «an ambulance always gets green first». Laya در همه‌ی ۲۵ حالتی که آمبولانس در خیابان خلوت‌تر بود، به آن سبز داد، حتی برخلاف جمله‌ی «صف طرف دیگر بیشتر است».

پاسخ‌ها را کش کن

برای یک متن و سؤال یکسان، جواب همیشه یکسان است. اگر تعداد حالت‌های ممکن محدود است، یک بار بپرس و نگه دار؛ ما این‌طور زمان تصمیم را از چند صد میلی‌ثانیه به چند میلی‌ثانیه رساندیم.

گزینه‌ها را توصیف کن

در choice به جای برچسب خالی، برای هر گزینه یک توضیح کوتاه بنویس ("billing": "invoices, payments, refunds"). مدل توضیح را می‌خواند، نه فقط اسم را.

برای دقت بیشتر fine-tune کن

طبق سازنده، روی بنچمارک «تصمیم‌های تایپ‌شده» مدل پایه ۰٫۳۶۲ دقت داشت و نسخه‌ی fine-tune شده ۰٫۷۶۶. یک notebook آماده برای Kaggle (دو GPU رایگان T4) در مخزن پروژه هست.
